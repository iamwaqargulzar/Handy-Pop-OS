# Handy v0.9.5 integration and recording-volume reduction

Date: 2026-08-10  
Target: Pop!\_OS / COSMIC Wayland

## Upgrade scope

The customized Pop!\_OS fork was merged with the signed upstream `v0.9.5`
release rather than replacing the working tree with an upstream package. The
integration retained the native GTK multi-monitor overlay, compact-to-wide
animation, dark defaults, blue Linux tray icon, model-switch hotkeys,
sleep/resume shortcut recovery, CLI model switching, and post-processing
fallback chain.

The merge had real conflicts in build instructions, post-processing actions,
startup, overlay placement, shortcuts, tray handling, generated TypeScript
bindings, and theme defaults. Each conflict was resolved explicitly. Upstream
microphone recovery, safer mute restoration, Linux memory trimming, model
download hardening, and paste/overlay fixes were retained.

## Output-volume reduction

General Settings > Sound now contains **Lower Volume While Recording**. It is
a percentage slider from 0% through 90% in 5% steps:

- 0% disables the feature;
- a nonzero value reduces the volume relative to its current level (for
  example, 50% changes a current 80% level to 40%);
- saved application and master-output levels are never changed on PipeWire;
- full **Mute While Recording** takes precedence and disables the slider; and
- restoration also runs during microphone recovery and stream shutdown so an
  interrupted session cannot intentionally leave the output lowered.

On Linux, Handy creates a private PipeWire loopback sink, sets its output gain,
and temporarily rewires active playback links through it. It deliberately
leaves both application volumes and the physical output-device volume unchanged
because COSMIC displays a volume OSD and plays `audio-volume-change.oga` for
every master-sink change. The graph operations are runtime-only and do not write
WirePlumber stream-volume or target-device preferences.

The first per-stream implementation was withdrawn after a disappearing stream
left Brave's persisted channel volume at approximately 0.17%. Recovery restored
the known Brave value to 100% and a test Music role to 70%. The replacement has
a cleanup watchdog containing every original graph link. It restores those
links on normal stop, stream recovery, or application death, then removes the
loopback. If the required PipeWire tools are unavailable, COSMIC fails open
without attenuation rather than falling back to the master sink and triggering
its OSD. Other Linux desktops retain `wpctl`, `pactl`, and `amixer` master-volume
fallbacks. Windows uses the default endpoint-volume API and macOS uses system
output-volume commands.
