# Handy Pop!\_OS 0.9.5-popos.1

Released: 11 August 2026

Handy Pop!\_OS 0.9.5-popos.1 is the first public Pop!\_OS-focused package of the
offline desktop speech-to-text application. It targets Pop!\_OS 24.04, COSMIC
Wayland, PipeWire, and x86_64 systems.

## Highlights

- Native multi-monitor GTK layer-shell recording overlay that follows the
  pointer at each trigger
- Compact translucent dark overlay with live text, a soft shadow, cool-blue
  controls, and a smooth width transition
- Crash-safe PipeWire playback reduction that does not edit the physical
  output level or applications' saved volume values
- Independent cleanup watchdog verified against normal stop, disappearing
  playback streams, and a forced application crash
- Cool-blue Linux tray states and a dark neutral application theme
- Responsive COSMIC Wayland paste handling and hidden startup
- Best-effort global shortcut recovery after suspend and resume
- Per-model global hotkeys and `handy --load-model <query>` CLI switching
- Three-model post-processing fallback chain
- Linux update checks disabled to protect the custom behavior

## Install

Download `Handy_0.9.5_amd64.deb` and run:

```bash
sudo apt install ./Handy_0.9.5_amd64.deb
sudo usermod -aG input "$USER"
```

Log out and back in after the group command, then launch Handy from the
application menu.

The Debian package declares GTK layer shell, OpenBLAS, PipeWire tools,
WirePlumber, PulseAudio compatibility utilities, WebKitGTK, GTK 3, and the
application-indicator runtime as dependencies. Transcription models are
downloaded separately after installation.

## Known limitations

- Pop!\_OS 24.04 on x86_64 is the primary tested target.
- Low-level global shortcuts require `input` group membership and cannot
  bypass compositor security policy.
- Streams launched after recording has already started may remain at their
  normal playback level until the next recording.
