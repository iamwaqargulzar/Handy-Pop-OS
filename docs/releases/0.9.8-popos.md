# Handy Pop!\_OS 0.9.8-popos

Reliability release for the optional Intel NPU (OpenVINO) transcription route,
built on upstream Handy 0.9.7.
No interface, overlay, theme, or settings behavior changed.

## Fixes

- **NPU transcriptions stopped working after a while.** The NPU worker was
  terminated by the kernel as soon as the thread that loaded the model exited,
  so later transcriptions had to silently restart it and reload the model, and
  could be killed mid-transcription. The worker now watches the Handy process
  itself and still exits promptly if Handy crashes.
- **Whisper Large v3 Turbo (NPU) returned empty text** with "Translate to
  English" enabled. Turbo has no translation training, so it now transcribes
  instead. Use Whisper Large v3 for speech-to-English translation.
- **Qwen3-ASR in Auto language mode pasted `language English<asr_text>`** in
  front of the transcript. The header is now removed. Language codes Qwen does
  not recognize fall back to automatic detection.
- **Qwen3-ASR failed on recordings longer than about 76 seconds.** Long
  recordings are now split at a pause and the text is joined.
- **A hung NPU request left Handy stuck on "processing".** Worker requests now
  time out, and a stuck worker is restarted on the next transcription.

## Install

```bash
sudo apt install ./Handy_0.9.8-popos_amd64.deb
```

APT treats `0.9.8-popos` as an upgrade over `0.9.7` and `0.9.7-popos.1`. Downloaded models and
compiled NPU caches are kept.

## Verification

- 276 Rust library tests, Rust formatting, and whitespace checks passed.
- The packaged NPU worker was exercised through Handy's worker protocol from a
  thread that exits after loading (the original failure condition) with
  Whisper Large v3 INT8, Whisper Large v3 Turbo INT8, Qwen3-ASR 1.7B INT8, and
  Parakeet TDT v3, using real dictation recordings up to 90 seconds.
