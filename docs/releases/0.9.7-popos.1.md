# Handy Pop!\_OS 0.9.7-popos.1

This release integrates upstream Handy 0.9.6 and 0.9.7 while keeping the
Pop!\_OS fork's Linux behavior and interface changes as the higher-priority
implementation.

## What changed

- Added upstream shortcut activation modes, VAD backend selection, filler-word
  removal, audio-recorder reliability work, language coverage updates, and
  transcription lifecycle coordination from Handy 0.9.6/0.9.7.
- Retained the dynamic multi-monitor Wayland overlay, compact translucent blue
  styling, smooth width transition, blue tray icons, dark default theme, and
  Linux sleep/resume shortcut recovery.
- Retained Vulkan/CPU transcription and the optional Intel NPU route for
  Whisper Large v3, Qwen3-ASR, and Parakeet. Systems without a supported Intel
  NPU continue to operate normally and do not show NPU-only models.
- Retained compiled OpenVINO model caching and the first-load progress message.
- Retained configurable output-volume reduction with crash/startup recovery,
  dynamic model hotkeys, CLI model switching, and post-processing fallback
  priorities.
- Update checks remain disabled on Linux so an upstream package cannot silently
  replace the Pop!\_OS-specific build.

## Install

```bash
sudo apt install ./Handy_0.9.7_amd64.deb
```

The package is designed for Pop!\_OS 24.04. Ubuntu 24.04 is supported on a
best-effort basis; desktop integration and global shortcuts can still depend on
the compositor and session configuration.

Models and OpenVINO compiled caches are downloaded or generated separately and
are not counted as part of the installer size.

## Verification

The Debian package is 118 MiB compressed and reports an installed size of
335,641 KiB. The packaged binary was tested with the same 11-second English
sample on Vulkan, CPU, and Intel NPU. Vulkan and CPU produced the expected text;
the NPU tests passed with Whisper Large v3 INT8, Qwen3-ASR 1.7B INT8, and
Parakeet TDT v3.
